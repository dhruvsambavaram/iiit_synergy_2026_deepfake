# Grad-CAM (bonus deliverable)

Generated by `tools/gradcam.py` from the submitted ensemble (`submission/model_weights.pt`) on **holdout images only**
(never trained on; never test images). Each heatmap explains the **predicted class**: the fake score for predicted-fake
images, the real score for predicted-real images. It is computed on the final 7×7 feature map of each model and
averaged over the image and its horizontal flip, exactly as inference does.

* `examples_grid.png`: 3 confident-correct fakes, 3 confident-correct reals, the most confident false positive and
  false negative. Columns show each model and the ensemble.
* `class_mean_cams.png`: the mean heatmap over 150 holdout reals and 150 holdout fakes (faces are pre-aligned, so
  averaging is meaningful).

| Share of attention (mean CAM) | Real images | Fake images |
|---|---|---|
| Central 60% of width (the face) | **88.5%** | **83.0%** |
| Eyes band | 29.0% | 25.0% |
| Nose / cheeks band | 34.2% | 26.8% |
| Mouth / chin band | 20.2% | 24.0% |
| Forehead / hair | 14.2% | 18.0% |
| Bottom edge / neck | 2.3% | 6.2% |

**Findings**
1. Both decisions rest on the face itself, not on the background or image borders. That points to facial
   manipulation cues, not dataset shortcuts.
2. For fakes, the evidence spreads across the whole face (eyes, nose, mouth, and forehead edge), which is consistent
   with face-swap blending. For reals, it concentrates on the mouth and lower-central face.
3. The members attend to different regions. On fakes: Xception #1 the forehead and face boundary, Xception #2 the
   mouth and chin, DenseNet the eyes and centre, B0 a tight central region. This complementary attention is why the
   ensemble beats each single model.
4. Both shown errors are degradation cases, matching the corruption-suite weaknesses: a real photo with heavy speckle
   noise and a strong red cast is called fake (p = 0.96), and a heavily blurred fake is called real (p = 0.05).

**A methodological note:** a first pass explained the fake score for every image. On real images, that showed weak
fake evidence along the bottom edge, which looked like a possible border shortcut. Explaining the predicted class
instead removed it (bottom-edge share 2.3%). The pattern was an artifact of explaining the wrong class, not a model
shortcut.
